06 · 质量与教训

以 AI 悍马为底线，踩过的坑

QUALITY BAR达不到这一档不入镜
🚙APC 横着开模型朝向不统一 → 单独转 90°
🎥4 个机位全错else 吞掉分支 → 显式 elif
🔊BGM 盖过旁白−20 → −30 LUFS + 压低
🐢音乐生成卡死编码器跑在 CPU → 改 GPU
✂音乐提前收尾截尾 + 首尾交叉淡化
🧱房子只有一面墙参考图缺纵深 → 剔除
🎻配乐没代入感平淡铺底 → 战争片风格
🔀伪分支只换文字 → 换镜头
06 · 方法论

六条可复用的经验

🧾数据先于影像剧本是节点图
🎯基准镜头先行3 秒定标准再铺全片
🔁确定性管线任一步可单独重跑
🔀交互要有后果至少换画面
👂人只做试听试看其余自动推进
⛓资源串行不碰用户的工作流
