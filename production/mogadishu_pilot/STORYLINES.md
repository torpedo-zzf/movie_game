# 摩加迪沙之战：首支 HyperFrames 样片故事线

**范围：** 首支 60 秒视觉样片；完整交互影游仍按 10–15 分钟规划。  
**输出：** 1920×1080、30 fps；中文屏幕文字；实际分支选择由后续播放器实现，不烘焙进单一 MP4。  
**共同边界：** 史实结果固定；没有来源的对白、无线电录音、平民个人经历不伪造成纪录素材。样片先用可追溯地图、排版和动画，不使用付费素材。Qwen Image 2.1 在许可未解决前不用于可能商业发布的成片；Pexels 只作明确标注的通用氛围素材。

## 1. 【推荐】《任务开始后，计划变了》

**状态：已选定，进入分镜审阅。**

**装置与形式：** 一夜的行动时间线；镜头沿依据史料绘制的摩加迪沙地点示意连续推进。  
**为什么推荐：** 60–90 秒里有清楚的因果弧线，也能以可追溯地图和官方记录讲述，不需要虚构人物或对白。

观众先看到 1993 年 10 月 3 日的行动目标，随后发现一次抓捕行动在直升机坠落后转成救援行动。镜头沿时间线移动，最后从地图拉回来源对照，提示伤亡记录并不完整且统计口径存在差异。

- **前两秒：** 标明非比例的城市地点示意铺满画面；日期“1993.10.03”落下，随后出现“约 15:30｜行动开始”。
- **节拍：** 日期与地点 → 抓捕目标 → 24 人的来源用词 → 两架黑鹰坠落 → 选择先读哪处救援记录 → 01:55 汇合 → 伤亡记录差异与出处。
- **互动点：** 约第 35 秒选择先读第一处或第二处现场记录，两支在 01:55 汇合；片尾再选“任务与救援 / 城市与平民 / 政策后果”的强调角度。选择改变资料顺序和结尾重点，不改变战果。
- **画面：** 依据美国陆军官方战后报告地图绘制的地点示意；标明“非比例示意”，不伪装成卫星图或逐街导航路线。石灰灰 `#D9DCD7`、墨黑 `#171A18`、信号橙 `#C9593D`；橙色只用于时间推进和事件转折；无装饰性网格或 HUD。
- **声音：** 克制的 76 BPM 低脉冲；事件转折处脉冲停半拍；只加一次有画面原因的低音冲击；不使用伪造枪声或无线电。
- **史料锚点：** `F01`–`F04`、`F09`；地点示意优先按美国陆军官方战后报告的地图和文字记录重绘，并在画面标出来源。

## 2. 《75 / 84》

**装置与形式：** 统计口径对照；一个数字表在镜头中逐步变形为来源比较。  

影片不从战术行动开始，而从两份记录之间的差异开始：观众先看到联合国报告与《华盛顿邮报》对美军伤者人数的不同记录，再看到索马里伤亡总数同样无法由现有来源确定。结尾把“数字不同”落到史料范围和记录缺口上，而不是给出一个看似精确的统一答案。

- **前两秒：** 浅灰底上巨大的“75 ≠ 84”；下方分别标注“联合国报告 / 《华盛顿邮报》”。
- **节拍：** 75 与 84 分开 → 两份来源展开 → 18 名美军死亡的共同记录 → 索马里伤亡估计并列但不定论 → “统计有边界”。
- **画面：** 平面统计排版；混凝土灰 `#E1E3DF`、墨黑 `#151716`、警示红 `#B94032`；数字占画面高度 35%，来源文字至少 32 px；不出现三张并排卡片。
- **声音：** 88 BPM 的轻微敲击脉冲；两个数字分开时各有一次纸面触点声；无旁白，不加战斗音效。
- **史料锚点：** `F04`、`F05`；完整出处始终随数字出现。

## 3. 【大胆方案】《房间里的一夜》

**装置与形式：** 一个明确虚构的复合平民视角；固定室内空间从黄昏变化到黎明。  

观众跟随一位未具名、明确标为虚构的社区诊所帮手，在战斗夜里处理“先带邻居离开，还是先守住药品”的虚构选择。选择只改变这个复合角色的个人结局，片尾再回到可核实的历史记录；不暗示这个人物或事件细节是真实见证。

- **前两秒：** 白天室内的固定镜头；屏幕标注“虚构复合视角｜非真实见证”，随后出现“天黑前，先做哪件事？”
- **节拍：** 诊所关门前 → 选择优先照看谁/什么 → 夜色推进但战斗留在画外 → 选择导致不同的个人结果 → 片尾回到真实事件与不确定伤亡记录。
- **画面：** 单一、非特定的室内布景；窗光从暖白变冷灰；不使用真实居民照片、不复刻某个可识别家庭、不出现未经核实的具体街道或受伤者。
- **声音：** 低强度室内环境声与单一持续音；选择时短暂停声；不模拟枪声、喊叫或无线电，不使用真实人物对白。
- **制作条件：** 发布前需要熟悉索马里历史与文化的审阅；任何近似具体个人经历的段落都应删除或补充来源与许可。
- **史料锚点：** 宏观事件引用 `F01`、`F03`、`F05`、`F08`；角色、诊所、选择与结局均标为创作内容。

## 共用假设

样片先做 60 秒、16:9、中文屏幕文字、不配旁白；配乐只从可免费使用的来源中选，找不到合适曲目时暂不加音乐，不引入付费声音或素材。每个场景会独立渲染成视频节点，后续交给交互播放器处理选项和分支。

地图授权边界：当前不烘焙 Esri 在线影像瓦片。Esri [现行服务条款](https://www.esri.com/en-us/legal/terms/web-site-service)将免费访问限于非商业用途，商业使用需要另行许可；本样片先使用标注来源的原创非比例地点示意。若后续确认非商业展示，也需遵守地图署名要求。
